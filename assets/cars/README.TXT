Letakkan foto armada di folder ini dengan nama file lowercase model_tahun, contoh:
- avanza_2020.png
- brio_2021.jpg
- xpander_2022.webp

Foto yang sesuai akan dipilih otomatis berdasarkan model dan tahun kendaraan.
Saat ini hanya aset fallback umum yang disertakan; foto mobil perlu ditambahkan oleh pemilik proyek sebelum ZIP dideploy jika ingin gambar kendaraan spesifik.
