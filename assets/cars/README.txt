Letakkan foto armada persis di folder ini (`assets/cars/`). File dengan nama lowercase disarankan, contoh:
- avanza_2020.png
- brio_2021.jpg
- xpander_2022.webp

Foto yang sesuai akan dicari otomatis berdasarkan model dan tahun kendaraan, termasuk beberapa variasi kapitalisasi seperti `Avanza_2023.png`.
Saat ini hanya aset fallback umum yang disertakan; foto mobil perlu ditambahkan oleh pemilik proyek sebelum ZIP dideploy jika ingin gambar kendaraan spesifik.
